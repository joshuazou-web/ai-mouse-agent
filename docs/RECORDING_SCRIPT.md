# 短录屏脚本（总时长 ≤3 分钟）

开场（约 10 秒）
- 口播：SimTech AI 鼠标配套桌面 Agent。指哪、说哪、做哪。只有三个功能：Point、Speak、Do。
- 画面：菜单栏三按钮特写（原型阶段可用 CLI 终端代替）。

## 场景 1｜回邮件（30–60 秒）
1. Point：框选一封邮件正文。
2. Speak：按住说「回复并接受」。
3. Do：打开回复草稿窗，正文已填好；**不发送**。
成功画面：草稿窗 + auto_send=false。

## 场景 2｜表格出图（30–60 秒）
1. Point：框选表格区域。
2. Speak：「做成图表」。
3. Do：弹出/保存一张图表 PNG。
成功画面：图表文件出现。

## 场景 3｜报销归档（30–60 秒）
1. Point：框选收据/账单。
2. Speak：「归档报销」。
3. Do：本地 expenses / record JSON 多一条（商家、金额、日期）。
成功画面：结构化记录文件，无对外提交。

收尾（约 5 秒）
- 口播：零说明书，三功能，草稿与本地记录，不自动外发。
